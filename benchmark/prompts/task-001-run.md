# Task 001 실행 프롬프트

현재 Repository의 다음 문서를 먼저 읽고 과제를 수행하세요.

- `ai-coding-agent-benchmark/benchmark/experiment-definition.md`
- `ai-coding-agent-benchmark/benchmark/task-001.md`

현재 실행 중인 Coding Agent의 종류를 자신의 실행 환경을 기준으로 식별하세요.

- Codex CLI인 경우 Agent 식별자는 `codex`
- Claude Code인 경우 Agent 식별자는 `claude`

이번 작업은 ChatGPT/Codex와 Claude의 결과물을 동일 조건에서 비교하기 위한 독립 실험입니다.

## 실행 규칙

반드시 다음 조건을 지키세요.

1. 현재 Repository 내부에서 직접 작업합니다.
2. `benchmark/task-001.md`에 정의된 요구사항을 그대로 따릅니다.
3. 결과 문서는 채팅에만 출력하지 말고 Repository 내부에 실제 Markdown 파일로 생성합니다.
4. 자신의 Agent 전용 결과 디렉터리만 사용합니다.
5. 상대 Agent의 결과 디렉터리는 읽거나 수정하지 않습니다.
6. 상대 Agent가 어떤 결과를 작성할지 추측하거나 의식하지 않습니다.
7. 자기평가나 상대 Agent와의 비교 평가는 이번 단계에서 수행하지 않습니다.
8. 단순 제품 소개가 아니라 실제 개발자가 활용할 수 있는 관점에서 작성합니다.
9. 기술적 사실은 가능한 경우 공식 문서를 기준으로 확인합니다.
10. 확실하지 않은 기술적 내용은 사실처럼 단정하지 않습니다.
11. 현재 지원되는 기능과 향후 확장 아이디어를 구분합니다.
12. 불필요하게 장황하게 작성하지 않습니다.
13. 과제 수행에 필요한 파일과 폴더가 없다면 직접 생성합니다.
